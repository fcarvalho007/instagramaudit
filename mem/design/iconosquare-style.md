# AuditProfiles — Iconosquare-Inspired Report Style

## Visual DNA
Clean SaaS analytics dashboard inspired by Iconosquare.
Light-first, airy, white cards, pale blue/lavender/mint background gradients, subtle borders, minimal shadows, precise spacing.

## Palette (report light mode)
- Background base: #F6FAFF / #F8FBFF
- Sidebar pale blue: #EAF5FF
- Card white: #FFFFFF
- Border subtle: #E5EEF7 / #E8EDF4
- Text primary: #111827 / #0F172A
- Text secondary: #64748B / #6B7280
- Blue action: #169BFF / #0EA5E9
- Cyan accent: #00AFCB
- Green success/chart: #44D45A
- Purple chart: #8B5CF6
- Yellow/amber chart: #FBBF24
- Pink/red chart: #F43F5E
- Pastel icon backgrounds: blue #EAF6FF, green #EFFFF4, pink #FFEAF5, yellow #FFF7E4, purple #F3E8FF

## Card Patterns

### KPI cards
White card → large empty space → pastel circular icon badge → large number → short label → delta/micro-indicator → minimal noise.

### Chart cards
Small header (icon + title + info icon) → actions right → chart with very subtle grid lines → rounded pill legends → few colours → lots of white space.

### Post cards
Strong thumbnail → format chip → date/excerpt → compact metrics row → blue icons.

## Layout Patterns
- Top row: large KPI cards
- Mid: 2-column chart grid
- Full-width for temporal charts
- Post grids with small compact cards
- Competitor comparison as tables with soft blue column highlight

## Do
- White cards over pale gradient background
- Large numeric KPIs
- Small pastel circular icon badges
- Clean grid-based layouts
- Compact chart headers with icon + title + info/action icons
- Subtle grid lines in charts
- Legends as rounded pills
- Blue as primary action/data accent
- Green, purple, amber, pink, teal only as semantic/chart accents
- Cards aligned, heights consistent
- Post cards with strong thumbnails and compact metrics
- Clarity over decoration

## Do Not
- Heavy dark panels inside report
- Overuse glow/neon
- Cluttered cards
- Excessive gradients inside every component
- Gaming dashboard charts
- Too-small mobile navigation
- Hide key metrics in dense text
- Aggressive red for low performance — prefer soft amber/rose analytical states

## Tone
Premium, clean, analytical, calm, structured, trustworthy.
Inspired by Iconosquare, not a direct copy.

## Post Comparison ("2 melhores / 2 a melhorar")
- Cards smaller and aligned
- Clean thumbnails
- Compact inline metrics
- "Melhores 2" with soft blue/green
- "A melhorar" with very discreet amber/rose
- AI summary as lightweight card, not oversized box
- Short, clear title
